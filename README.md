# 🎬 App Gestíon de Clientes / Asignación y Gestión de Seguros - Angular 16

Aplicación web desarrollada con Angular 16 que consume API Rest en .Net 8 para crear, mostrar, eliminar,buscar y actualizar Clientes y Seguros, utilizando Bootstrap para el diseño responsivo.

# Back-end para este proyecto, está con arquitectura limpia
https://github.com/AlexRubenPaguay/SegurosNET8_Clean

## ✨ Características

    ✅ Consumo de API REST 

    ✅ Visualización de clientes y seguros
    
    ✅ Crear, mostrar, eliminar,buscar y actualización de clientes y seguros

    ✅ Búsqueda de clientes por: cédula,nombre o teléfono
    
    ✅ Búsqueda de seguros por: nombre de seguro o cédula de cliente

    ✅ Diseño responsivo con Bootstrap

    ✅ Interfaz moderna y amigable

## 🛠 Tecnologías Utilizadas

    Angular 16 - Framework frontend

    Bootsttrap - Framework CSS

    TypeScript - Superset tipado de JavaScript

    RxJS - Programación reactiva    

## 📦 Requisitos Previos

    Node.js (versión 16 o superior)

    npm (versión 8 o superior)

    Angular CLI 16

    Visual Studio Code (recomendado)
